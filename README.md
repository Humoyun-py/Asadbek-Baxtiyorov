# Asadbek Baxtiyorov — Portfolio

React + Vite + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build -> dist/
```

- Barcha kontent: `src/data/` (projects.ts, statistics.ts, services.ts).
- Skrinshotlar taqdimotdan olingan: `src/assets/projects/`, `src/assets/meta-ads-manager.png`.
- Portret qo'shish: rasmni `src/assets/portrait.png` (yoki .jpg/.webp) nomi bilan joylashtiring — Hero avtomatik ishlatadi.
